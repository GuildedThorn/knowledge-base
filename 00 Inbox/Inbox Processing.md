## Purpose

Process rough notes from `00 Inbox` into the correct long-term location.

## When To Process

- after a work session
- at the end of the day
- when the inbox starts getting noisy

## Processing Checklist

1. Decide whether the note is worth keeping.
2. If it is junk, delete it.
3. If it is useful but unfinished, move it into `08 Improvements` or `07 Projects`.
4. If it is stable reference material, move it into the correct permanent folder.
5. Rename the note so the title is clear and searchable.
6. Add links to the right map note.
7. Split the note if it contains more than one topic.

## Common Destinations

- `02 Systems` for NixOS, host config, auth, secrets, and deployment flow
- `03 Devices` for hardware-specific notes
- `04 Software` for app-specific notes
- `05 Network` for firewall, routing, DNS, VPN, and recovery
- `06 Reference` for command snippets and reusable reference material
- `07 Projects` for active project documentation
- `08 Improvements` for unfinished work and follow-up

## Rule

Do not try to make inbox notes pretty. Move useful knowledge out of the inbox instead.
