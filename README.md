# knowledge-base

My Obsidian knowledge base for **ThornCloud** — networks, devices, software, NixOS hosts, projects, and the setup notes that keep it running.

## Start here

- **[`INDEX.md`](INDEX.md)** — auto-generated catalog of every note (slug · status · summary). Read this first to see the whole vault at a glance; it's regenerated on every commit by `.claude/gen-index.py`.
- **[`Welcome.md`](Welcome.md)** — human orientation and folder guide.
- **[`01 Maps/`](01%20Maps)** — maps of content, one per area.
- **[`06 Reference/Codex Generation Standard.md`](06%20Reference/Codex%20Generation%20Standard.md)** — how notes in here are written (frontmatter, structure, token discipline).

## Conventions

Every note carries YAML frontmatter (`summary` / `status` / `tags`). IPs and host addresses live once in [`05 Network/Host & IP Inventory.md`](05%20Network/Host%20%26%20IP%20Inventory.md). Superseded content is retired to `99 Archive/`, not deleted.
