# Reversing - Index

## Purpose

Index of malware reverse-engineering, triage, unpacking, anti-analysis, and signature-writing notes.

## Notes

- [Anti-Analysis Techniques](kb://11-security-reversing-anti-analysis-techniques) - Anti-analysis techniques detect, delay, mislead, or break sandboxes, debuggers, virtual machines, and reverse-engineering workflows.
- [Dynamic Malware Analysis](kb://11-security-reversing-dynamic-malware-analysis) - Dynamic malware analysis executes a sample in a controlled lab to observe process, file, registry, network, and memory behavior.
- [Packers and Unpacking](kb://11-security-reversing-packers-and-unpacking) - Packers compress, encrypt, or virtualize malware code so static analysis sees a wrapper before the real payload is reconstructed.
- [Shellcode Analysis](kb://11-security-reversing-shellcode-analysis) - Shellcode analysis reconstructs small position-independent payloads that resolve APIs, stage network access, or bootstrap larger malware.
- [Static Malware Triage](kb://11-security-reversing-static-malware-triage) - Static malware triage extracts file facts, strings, imports, metadata, packer hints, and configuration clues before executing a sample.
- [YARA Rule Writing](kb://11-security-reversing-yara-rule-writing) - YARA rules describe malware or file traits with strings, byte patterns, modules, metadata, and boolean conditions.
