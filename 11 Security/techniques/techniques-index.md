# Techniques - Index

## Purpose

Index of reusable ATT&CK-style technique notes for defensive research, hunting, and detection design.

## Notes

- [AMSI and ETW Bypass](kb://11-security-techniques-amsi-etw-bypass) - AMSI and ETW bypasses attempt to blind Windows script and telemetry inspection by patching, disabling, or evading instrumentation paths.
- [Credential Access Overview](kb://11-security-techniques-credential-access-overview) - Credential access is the theft, dumping, capture, or abuse of authentication material that enables privilege and lateral movement.
- [DLL Sideloading and Search Order Hijacking](kb://11-security-techniques-dll-sideloading-and-search-order-hijacking) - DLL sideloading abuses trusted executables and Windows library search behavior to run attacker-controlled DLL code.
- [Living off the Land and LOLBins](kb://11-security-techniques-living-off-the-land-lolbins) - Living-off-the-land tradecraft abuses trusted binaries, scripts, libraries, and admin tools for execution, transfer, evasion, or discovery.
- [LSASS Credential Dumping](kb://11-security-techniques-lsass-credential-dumping) - LSASS dumping targets Windows authentication material in memory to steal hashes, tickets, or cleartext-equivalent credentials.
- [Persistence Patterns](kb://11-security-techniques-persistence-patterns) - Persistence techniques preserve adversary access across reboots, credential changes, remediation attempts, and service restarts.
- [Process Injection](kb://11-security-techniques-process-injection) - Process injection hides execution inside another process to evade process-based defenses or inherit access from the target process.
