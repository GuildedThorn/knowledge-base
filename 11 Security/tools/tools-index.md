# Offensive Tools — Index

Per-tool references: the flags and invocations you actually reach for. Methodology lives in the [Pentest Playbook](kb://11-security-playbook-pentest-playbook-index); this is the "how do I drive the tool" layer.

## Recon & web

- [nmap](kb://11-security-tools-nmap) — port/service scanning, NSE
- [ffuf & gobuster](kb://11-security-tools-ffuf-gobuster) — content/vhost/param fuzzing
- [Burp Suite](kb://11-security-tools-burp-suite) — intercepting proxy, Repeater/Intruder
- [sqlmap](kb://11-security-tools-sqlmap) — automated SQLi detection/exploitation/dump

## Exploitation & AD

- [Metasploit](kb://11-security-tools-metasploit) — exploit framework, msfvenom, meterpreter
- [hashcat & john](kb://11-security-tools-hashcat-john) — offline hash cracking
- [impacket & netexec](kb://11-security-tools-impacket-netexec) — SMB/AD/Kerberos toolkit, exec, spraying
- [BloodHound](kb://11-security-tools-bloodhound) — AD attack-path graph

## Analysis / defense

- [Wireshark & tcpdump](kb://11-security-tools-wireshark) — capture, dissect, extract creds/files
- [Ghidra](kb://11-security-tools-ghidra) — disassembly/decompilation, static RE
- [Atomic Red Team](kb://11-security-tools-atomic-red-team) — purple-team detection tests mapped to MITRE ATT&CK; validate the SIEM/SOC pipeline
