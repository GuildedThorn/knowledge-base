# Threat Intel - Index

## Purpose

Index of malware-family, threat-actor, and campaign digests in the security research library.

## Notes

- [APT29 / Midnight Blizzard](kb://11-security-threat-intel-apt29-midnight-blizzard) - APT29 is a Russian SVR-attributed cluster associated with stealthy espionage, cloud identity abuse, and supply-chain compromise.
- [Emotet](kb://11-security-threat-intel-emotet) - Modular Windows loader and ransomware delivery ecosystem.
- [FIN7](kb://11-security-threat-intel-fin7) - FIN7 is a financially motivated intrusion cluster that moved from point-of-sale theft toward big-game ransomware operations.
- [Lazarus Group](kb://11-security-threat-intel-lazarus-group) - Lazarus is a DPRK-attributed umbrella for espionage, destructive operations, and financially motivated cyber activity.
- [LockBit Ransomware](kb://11-security-threat-intel-lockbit-ransomware) - LockBit is a ransomware-as-a-service ecosystem whose affiliates vary widely but converge on credential abuse, data theft, and fast encryption.
- [Mirai Botnet](kb://11-security-threat-intel-mirai-botnet) - Mirai showed how default credentials and unmanaged IoT fleets can scale into internet-impacting DDoS botnets.
- [SolarWinds SUNBURST](kb://11-security-threat-intel-solarwinds-sunburst) - SUNBURST was a trojanized SolarWinds Orion update path used for stealthy downstream access and cloud identity compromise.
- [Stuxnet](kb://11-security-threat-intel-stuxnet) - Stuxnet is the canonical public case of malware bridging Windows intrusion tradecraft into industrial-control sabotage.
- [TrickBot and QakBot](kb://11-security-threat-intel-trickbot-qakbot) - TrickBot and QakBot are modular banking-trojan loader ecosystems that evolved into ransomware delivery infrastructure.
