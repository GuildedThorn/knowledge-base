# DFIR & Detection - Index

## Purpose

Index of incident-response, forensics, hunting, and detection-engineering references.

## Notes

- [Incident Response Lifecycle](kb://11-security-dfir-detection-incident-response-lifecycle) - NIST SP 800-61 Rev. 3 reframes incident response as CSF 2.0-aligned risk management across Govern, Identify, Protect, Detect, Respond, and Recover.
- [Memory Forensics with Volatility](kb://11-security-dfir-detection-memory-forensics-volatility) - Memory forensics recovers runtime artifacts such as processes, modules, handles, sockets, credentials, injected code, and malware state.
- [Sigma Detection Engineering](kb://11-security-dfir-detection-sigma-detection-engineering) - Sigma is a portable YAML detection-rule format for expressing log analytics across SIEM backends.
- [Threat-Informed Defense and D3FEND](kb://11-security-dfir-detection-threat-informed-defense-d3fend) - Threat-informed defense maps real adversary behavior to defensive controls, using ATT&CK for behavior and D3FEND for countermeasure vocabulary.
- [Velociraptor DFIR](kb://11-security-dfir-detection-velociraptor-dfir) - Velociraptor gives defenders endpoint collection, hunting, artifact packaging, notebooks, and remote forensic analysis at fleet scale.
- [Windows Event Log Triage](kb://11-security-dfir-detection-windows-event-log-triage) - Windows event triage correlates authentication, process, service, PowerShell, task, Defender, and Sysmon events into an incident timeline.
