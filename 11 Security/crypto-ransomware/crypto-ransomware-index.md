# Crypto & Ransomware - Index

## Purpose

Index of ransomware, cryptography-adjacent abuse, code-signing, password, and supply-chain notes.

## Notes

- [Code-Signing Abuse](kb://11-security-crypto-ransomware-code-signing-abuse) - Code-signing abuse turns trust infrastructure into an evasion and supply-chain risk when certificates, build systems, or signed binaries are misused.
- [Hash Cracking and Password Storage](kb://11-security-crypto-ransomware-hash-cracking-and-password-storage) - Password security depends on slow, salted password hashing, strong user choices, MFA, and rapid credential rotation after exposure.
- [Ransomware Encryption and Extortion](kb://11-security-crypto-ransomware-ransomware-encryption-and-extortion) - Modern ransomware combines file encryption, data theft, leak-site extortion, and operational pressure against recovery workflows.
- [Ransomware Response and Recovery](kb://11-security-crypto-ransomware-ransomware-response-and-recovery) - Ransomware response is a coordinated containment, evidence, identity, restoration, legal, and communications problem.
- [Software Supply Chain Security](kb://11-security-crypto-ransomware-software-supply-chain-security) - Software supply-chain defense protects source, dependencies, builds, signing, provenance, release, and procurement trust decisions.
