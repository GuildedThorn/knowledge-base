# Web-Advanced - Index

## Purpose

Index of advanced web application vulnerability notes beyond the basic OWASP Top 10 checklist.

## Notes

- [GraphQL API Security](kb://11-security-web-advanced-graphql-api-security) - GraphQL security failures cluster around authorization, introspection exposure, batching abuse, expensive queries, and resolver injection.
- [HTTP Request Smuggling](kb://11-security-web-advanced-http-request-smuggling) - Parser desynchronization between front-end and back-end HTTP components.
- [Insecure Deserialization](kb://11-security-web-advanced-insecure-deserialization) - Unsafe object reconstruction and gadget-chain risk.
- [JWT Attacks](kb://11-security-web-advanced-jwt-attacks) - JWT signing, validation, and claim abuse.
- [OAuth, OIDC, and SAML Attacks](kb://11-security-web-advanced-oauth-oidc-saml-attacks) - OAuth/OIDC/SAML bugs usually come from trust-boundary mistakes in redirect validation, token validation, metadata, and assertion handling.
- [Prototype Pollution](kb://11-security-web-advanced-prototype-pollution) - JavaScript object prototype mutation as an application attack surface.
- [Server-Side Request Forgery](kb://11-security-web-advanced-ssrf) - Server-side request abuse against internal services and cloud metadata.
- [Server-Side Template Injection](kb://11-security-web-advanced-server-side-template-injection) - SSTI occurs when user input is interpreted as server-side template code instead of data, often escalating to server compromise.
