# Cloud & Container - Index

## Purpose

Index of cloud, container, Kubernetes, CI/CD, and metadata-security research notes.

## Notes

- [AWS IAM Privilege Escalation](kb://11-security-cloud-container-aws-iam-privilege-escalation) - AWS IAM privilege escalation abuses dangerous permission combinations to create, pass, update, or assume more powerful access.
- [CI/CD Pipeline Abuse](kb://11-security-cloud-container-ci-cd-pipeline-abuse) - CI/CD abuse targets workflow tokens, secrets, runners, dependencies, artifact provenance, and deployment permissions.
- [Cloud Detection and Logging](kb://11-security-cloud-container-cloud-detection-logging) - Cloud detection depends on control-plane audit logs, identity events, network flow, workload telemetry, and service-specific data events.
- [Cloud IMDS and Metadata Abuse](kb://11-security-cloud-container-cloud-imds-and-metadata-abuse) - Cloud metadata abuse turns SSRF or local code execution into access to instance metadata, temporary credentials, and cloud identity context.
- [Container Escape and Runtime Hardening](kb://11-security-cloud-container-container-escape-and-runtime-hardening) - Container escape risk rises when workloads run privileged, mount host resources, expose runtimes, or lack kernel isolation controls.
- [Kubernetes Threat Matrix](kb://11-security-cloud-container-kubernetes-threat-matrix) - Kubernetes attack modeling covers cluster, node, workload, registry, identity, CI/CD, and control-plane abuse paths.
