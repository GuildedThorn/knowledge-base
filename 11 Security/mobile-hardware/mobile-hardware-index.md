# Mobile & Hardware - Index

## Purpose

Index of mobile, firmware, IoT, UEFI, and hardware-security research notes.

## Notes

- [Android Security and Malware Analysis](kb://11-security-mobile-hardware-android-security-and-malware-analysis) - Android analysis combines app sandboxing, permissions, APK structure, manifest review, code/resource analysis, dynamic hooks, and network observation.
- [Apple Platform Security and iOS](kb://11-security-mobile-hardware-apple-platform-security-ios) - Apple platform security layers hardware roots of trust, secure boot, code signing, sandboxing, data protection, and privacy controls.
- [Fault Injection and Hardware Attacks](kb://11-security-mobile-hardware-fault-injection-and-hardware-attacks) - Fault injection manipulates voltage, clock, electromagnetic, optical, or environmental conditions to disturb hardware execution or checks.
- [Firmware Analysis Workflow](kb://11-security-mobile-hardware-firmware-analysis-workflow) - Firmware analysis extracts, identifies, unpacks, and inspects device images for filesystems, secrets, services, vulnerabilities, and update trust.
- [IoT Botnets and Device Hardening](kb://11-security-mobile-hardware-iot-botnets-and-device-hardening) - IoT botnets exploit weak device management, default credentials, exposed services, and unpatchable embedded fleets.
- [Mobile App Security with MASVS](kb://11-security-mobile-hardware-mobile-app-security-masvs) - OWASP MASVS provides a control framework for mobile app security across storage, crypto, auth, network, platform, code, resilience, and privacy.
- [UEFI Bootkits and Secure Boot](kb://11-security-mobile-hardware-uefi-bootkits-and-secure-boot) - UEFI bootkits persist below the operating system by modifying boot components, weakening trust in startup and endpoint remediation.
