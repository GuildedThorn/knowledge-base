# AI, ML, and Agent Systems - Index

## Purpose

ML foundations, transformers, embeddings, RAG, inference, evaluation, MLOps, speech, vision, and agent-system notes.

## Notes

- [AI Agent Tool Use](kb://06-reference-engineering-ai-ml-systems-ai-agent-tool-use) - Agent systems let models call tools, read state, write artifacts, and iterate, so reliability depends on permissions, state, planning, and verification.
- [Computer Vision: CNNs and Vision Transformers](kb://06-reference-engineering-ai-ml-systems-computer-vision-cnns-and-vision-transformers) - Computer vision models extract visual features for classification, detection, segmentation, tracking, and multimodal understanding.
- [Data Labeling and Dataset Quality](kb://06-reference-engineering-ai-ml-systems-data-labeling-and-dataset-quality) - Dataset quality determines model behavior; labeling policy, sampling, provenance, and review matter as much as model selection.
- [Embeddings and Vector Search](kb://06-reference-engineering-ai-ml-systems-embeddings-and-vector-search) - Embeddings map items into vector space so semantic similarity can be searched with approximate nearest-neighbor indexes.
- [Evals and Benchmarks](kb://06-reference-engineering-ai-ml-systems-evals-and-benchmarks) - AI evaluations measure model behavior on task-specific datasets, rubrics, adversarial cases, and regression suites.
- [GPTKB: LLM Knowledge Base Construction](kb://06-reference-engineering-ai-ml-systems-gptkb-llm-knowledge-base-construction) - GPTKB constructs a large general-domain knowledge base from an LLM using iterative graph expansion, prompting, NER, consolidation, clustering, taxonomy construction, and deduplication.
- [LLM Inference, KV Cache, and Quantization](kb://06-reference-engineering-ai-ml-systems-llm-inference-kv-cache-and-quantization) - LLM inference performance is dominated by prefill/decode phases, KV cache memory, batching, quantization, and memory bandwidth.
- [LLM Serving: PagedAttention, FlashAttention, and TensorRT-LLM](kb://06-reference-engineering-ai-ml-systems-llm-serving-pagedattention-flashattention-tensorrt) - Modern LLM serving improves throughput and latency with KV-cache management, IO-aware attention kernels, batching, quantization, and GPU-specific runtimes.
- [MLOps and Data Versioning](kb://06-reference-engineering-ai-ml-systems-mlops-data-versioning) - MLOps coordinates datasets, features, training code, model artifacts, evaluation, deployment, monitoring, and rollback.
- [Model Serving Patterns](kb://06-reference-engineering-ai-ml-systems-model-serving-patterns) - Model serving turns trained artifacts into reliable APIs with batching, autoscaling, versioning, monitoring, and rollback.
- [Recommendation Systems](kb://06-reference-engineering-ai-ml-systems-recommendation-systems) - Recommendation systems rank items for users using signals, candidate generation, scoring, exploration, and feedback loops.
- [Reinforcement Learning Basics](kb://06-reference-engineering-ai-ml-systems-reinforcement-learning-basics) - Reinforcement learning trains agents to choose actions in environments by optimizing expected reward over time.
- [Retrieval-Augmented Generation](kb://06-reference-engineering-ai-ml-systems-rag-systems) - RAG grounds model responses in retrieved external context, combining indexing, retrieval, ranking, prompting, generation, and citation checks.
- [Speech: STT and TTS](kb://06-reference-engineering-ai-ml-systems-speech-stt-and-tts) - Speech systems convert audio to text and text to speech using acoustic features, sequence models, vocoders, alignment, and latency-aware pipelines.
- [Transformers and Attention](kb://06-reference-engineering-ai-ml-systems-transformers-and-attention) - Transformers use attention over token sequences to build contextual representations and power modern language, vision, and multimodal models.
