# Algorithms and CS - Index

## Purpose

Algorithmic foundations, data structures, complexity, graph algorithms, dynamic programming, and computability notes.

## Notes

- [Balanced Trees and B-Trees](kb://06-reference-engineering-algorithms-cs-balanced-trees-and-b-trees) - Balanced search trees guarantee logarithmic operations; B-trees optimize search trees for block/page-oriented storage.
- [Bloom Filters and Probabilistic Structures](kb://06-reference-engineering-algorithms-cs-bloom-filters-and-probabilistic-structures) - Probabilistic data structures trade exactness for compact memory and speed when false positives or approximations are acceptable.
- [Complexity Analysis and Asymptotics](kb://06-reference-engineering-algorithms-cs-complexity-analysis-and-asymptotics) - Complexity analysis estimates how resource use scales with input size so engineers can compare algorithms independent of one machine.
- [Dynamic Programming Patterns](kb://06-reference-engineering-algorithms-cs-dynamic-programming-patterns) - Dynamic programming solves problems with overlapping subproblems and optimal substructure by caching or tabulating intermediate results.
- [Graph Traversal: BFS and DFS](kb://06-reference-engineering-algorithms-cs-graph-traversal-bfs-dfs) - BFS and DFS are the two basic graph exploration strategies behind reachability, connected components, shortest unweighted paths, and dependency analysis.
- [Greedy Algorithms and Exchange Arguments](kb://06-reference-engineering-algorithms-cs-greedy-algorithms-and-exchange-arguments) - Greedy algorithms make locally optimal choices; proof usually requires an exchange argument, matroid-like structure, or cut property.
- [Hash Tables and Hashing](kb://06-reference-engineering-algorithms-cs-hash-tables-and-hashing) - Hash tables trade ordered traversal for expected constant-time lookup, insertion, and deletion under a good hash distribution.
- [Heaps and Priority Queues](kb://06-reference-engineering-algorithms-cs-heaps-and-priority-queues) - Heaps implement priority queues for repeatedly extracting the smallest or largest item without fully sorting every update.
- [NP-Completeness and Approximation](kb://06-reference-engineering-algorithms-cs-np-completeness-and-approximation) - NP-completeness explains why many optimization problems resist known polynomial-time exact algorithms and need approximation, heuristics, or constraints.
- [Randomized and Online Algorithms](kb://06-reference-engineering-algorithms-cs-randomized-and-online-algorithms) - Randomized and online algorithms handle uncertainty by using probability, competitive analysis, or decisions without full future knowledge.
- [Shortest Paths: Dijkstra, Bellman-Ford, and A*](kb://06-reference-engineering-algorithms-cs-shortest-paths-dijkstra-bellmanford-astar) - Shortest-path algorithms differ by edge weights, negative edges, graph size, and whether a target-specific heuristic is available.
- [Sorting Algorithms](kb://06-reference-engineering-algorithms-cs-sorting-algorithms) - Sorting is the foundation for searching, joins, deduplication, ranking, external processing, and many data-processing pipelines.
- [String Search and Indexes](kb://06-reference-engineering-algorithms-cs-string-search-and-indexes) - String algorithms support search, autocomplete, diffing, genomics, compilers, log scanning, and text indexing.
- [Union-Find / Disjoint Sets](kb://06-reference-engineering-algorithms-cs-union-find-disjoint-sets) - Union-find tracks dynamic connectivity with near-constant amortized operations using union by rank and path compression.
