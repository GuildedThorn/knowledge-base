# 3D Mapping Platforms - Index

## Purpose

Comparison hub for the major 3D mapping platforms relevant to globe, city, terrain, and geospatial visualization work.

## Platform Notes

- [Esri ArcGIS Pro 3D GIS](kb://06-reference-3d-mapping-platforms-esri-arcgis-pro-3d-gis) - Enterprise GIS system of record with local/global scenes, scene layers, I3S, editing, analysis, and ArcGIS Online/Enterprise publishing.
- [Google Maps Platform Photorealistic 3D Tiles](kb://06-reference-3d-mapping-platforms-google-maps-platform-photorealistic-3d-tiles) - Official Google 3D mesh access through Map Tiles API and OGC 3D Tiles-compatible renderers.
- [Mapbox GL JS 3D Terrain and Buildings](kb://06-reference-3d-mapping-platforms-mapbox-gl-js-3d-terrain-and-buildings) - Client-side web maps with vector styling, raster DEM terrain, hillshade, and fill-extrusion buildings.
- [CesiumJS 3D Geospatial Visualization](kb://06-reference-3d-mapping-platforms-cesiumjs-3d-geospatial-visualization) - Open web globe built around 3D Tiles, terrain, imagery, time-dynamic visualization, and massive geospatial streaming.
- [Xweather MapsGL Weather Visualization](kb://06-reference-3d-mapping-platforms-xweather-mapsgl-weather-visualization) - WebGL weather mapping SDK for animated weather layers, particles, contours, timelines, and third-party map integration.
- [Eagleview Aerial Imagery and Property Intelligence](kb://06-reference-3d-mapping-platforms-eagleview-aerial-imagery-and-property-intelligence) - High-resolution aerial imagery, property measurements, AI-derived attributes, reports, APIs, and property intelligence workflows.
- [OpenEarth.Online 3D Mesh Export](kb://06-reference-3d-mapping-platforms-openearth-online-3d-mesh-export) - Commercial Earth/Pano Studio service for searching, fetching, and exporting 3D earth tiles and panoramas for AI, CG, BIM, simulation, and digital-twin workflows.
- [3D Mapping Platform Selection Matrix](kb://06-reference-3d-mapping-platforms-3d-mapping-platform-selection-matrix) - Quick technical comparison for choosing between the four platforms.

## Quick Selection

- Use **ArcGIS Pro** when authoritative GIS editing, enterprise data management, geoprocessing, and ArcGIS sharing are primary.
- Use **Google Maps Platform Photorealistic 3D Tiles** when high-fidelity real-world urban mesh coverage is the core requirement and Google licensing/API key constraints are acceptable.
- Use **Mapbox GL JS** when the deliverable is a dynamic browser map with custom styling, vector overlays, 3D buildings, and terrain rather than full photogrammetry.
- Use **CesiumJS** when the deliverable is an open 3D globe/web scene that streams heterogeneous 3D geospatial datasets using 3D Tiles.
- Use **Xweather MapsGL** when the differentiator is animated weather visualization rather than basemap ownership.
- Use **Eagleview** when the differentiator is property-level aerial imagery, measurements, and parcel/building intelligence.
- Use **OpenEarth.Online** when the need is offline mesh/panorama export into DCC/BIM/game tools, subject to licensing review.
