# Engineering Research Library

## Purpose

Broad source-cited engineering corpus for turning the vault into a working technical fortress: language/runtime knowledge, computer-science fundamentals, operating systems, distributed systems, databases, protocols, architecture, operations, graphics/VR, and AI/ML systems.

## Collections

- [C# and .NET - Index](kb://06-reference-engineering-csharp-dotnet-csharp-dotnet-index) - C#/.NET language, runtime, libraries, diagnostics, web, data, and deployment reference notes.
- [Algorithms and CS - Index](kb://06-reference-engineering-algorithms-cs-algorithms-cs-index) - Algorithmic foundations, data structures, complexity, graph algorithms, dynamic programming, and computability notes.
- [Systems and Distributed Computing - Index](kb://06-reference-engineering-systems-distributed-systems-distributed-index) - Distributed systems papers and design notes: consensus, clocks, replication, logs, storage systems, and failure handling.
- [Databases and Storage - Index](kb://06-reference-engineering-databases-storage-databases-storage-index) - Database internals, storage engines, indexing, transactions, SQL, schema design, and recovery notes.
- [Linux, Nix, and Systems - Index](kb://06-reference-engineering-linux-nix-systems-linux-nix-systems-index) - Linux operating-system concepts, systemd, containers, Nix language, NixOS modules, flakes, and reproducibility notes.
- [Networking and Protocols - Index](kb://06-reference-engineering-networking-protocols-networking-protocols-index) - Internet protocols, HTTP, TLS, QUIC, DNS, routing, load balancing, gRPC, and service connectivity notes.
- [Software Architecture - Index](kb://06-reference-engineering-software-architecture-software-architecture-index) - Architecture patterns, API design, DDD, event-driven systems, testing strategy, ADRs, and legacy-system evolution notes.
- [Observability and SRE - Index](kb://06-reference-engineering-observability-sre-observability-sre-index) - SRE, observability, alerting, traces, metrics, logs, incident management, capacity, and operations notes.
- [Graphics, VR, and GPU Compute - Index](kb://06-reference-engineering-graphics-vr-compute-graphics-vr-compute-index) - Rendering, GPU architecture, shaders, VR latency, OpenXR, spatial audio, terrain LOD, and profiling notes.
- [AI, ML, and Agent Systems - Index](kb://06-reference-engineering-ai-ml-systems-ai-ml-systems-index) - ML foundations, transformers, embeddings, RAG, inference, evaluation, MLOps, speech, vision, and agent-system notes.

## Conventions

- One topic per note.
- Notes are digests, not raw mirrors of source material.
- Each topic note carries a `## Sources` section.
- Prefer official docs, primary papers, standards, and canonical long-form references.
- Keep implementation decisions in project notes; keep reusable knowledge here.
